## 覆盖说明

- **等价类**:有效类(TC-001/003/004/005/006/010)、无效类(其余),覆盖"太长/太短/空/错误/非法字符"多个方向。
- **边界值**:用户名下边界 3(上点/内点/离点 2/3/4)、上边界 20(19/20/21);密码边界 6。
- 用这套思路,以后任何功能的用例都能按"等价类分类 + 边界取值 + 正常/异常"系统地列出来,而不是随机凑数。
